# Frontend — Highsoft Course Portal

## Description

The frontend is responsible for the user interface of the Highsoft Course Portal.

It will allow students to browse courses, follow lessons, and view their learning progress.

## Technologies

- HTML — page structure
- CSS — styling and responsive design
- JavaScript — user interactions and communication with the backend

## Backend Connection

The frontend will use JavaScript to communicate with the Flask backend through API requests.

The backend will provide course information, lesson content, and progress data.
